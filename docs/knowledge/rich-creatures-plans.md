**Code map** (src/render/models): `rich-creatures.js` has PLANS = [quad, bird, serpent, reptile, insect (the beetle), ram], each {supported(v, unitType), build(unitType, ctx)}, asked by rich-humanoid.js (`creatureSupported` / `buildCreatureTemplate`); it must not import rich-humanoid.js; `normalizeVisual` caps `heads` at 9. Kit: `rich-creature-kit.js` (creatureSpec/addBones, bonesOf, pathStations, ringPoint, frameMatrix, headToModel, intoBone), `rich-creature-parts.js` (tuft, paw, hoof, collar, spike, halo), `rich-creature-hair.js`, `rich-creature-wings.js`, `rich-mammal-heads.js`, `rich-reptile-heads.js`. Plans: `rich-quadruped.js`, `rich-bird.js` (+ `rich-bird-heads.js`), `rich-serpent.js`, `rich-reptile.js`. Pose: `rich-creature-anim.js` `applyCreature` switches on `R.plan`; unit-anim.js calls it when `m.rich`.

**Rules**: the old pose keys in unit-anim.js stay the source of truth (quad `bY bRz hRz jaw tailA gFL kFL`, bird `wing bRz bX bY fold`, serpent/hydra/dragon `st jaw lunge ga wing fold` plus `m.wavePhase`, `m.walkPhase`, `m.moving`, `m.air`, `m.seed`). Bones are plain pivots, parents before children. Template `kind` stays the old kind so the animate switch still dispatches. Budgets: creature 10500, minion 8500, titan 14000 triangles. Humanoids must stay vertex-identical to main (checksum script).
