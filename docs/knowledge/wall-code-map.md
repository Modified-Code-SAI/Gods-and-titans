# wall-code-map

> Where the wall code lives (data, sim, wire, render, HUD) and its gotchas: connection masks, two meshes a segment, the stone swap on the wire, loops that must skip walls

Code map for [walls](walls.md) (PR #18, plus the review follow-up #19).

- Data: src/data/walls.js (`isWallType`, `wallUpgradeOf`, `wallLine`, `wallMask`, `wallConnections`); `wallUpgrade` on `wooden_wall` and `joinsWalls` on `tower` in data/buildings.js.
- Sim: `issueBuildLine` (sim/construction.js; skips tiles out of `wallInReach`, i.e. farther than `WALL_PLACE_RANGE` from every ordered worker; `buildableDef` limits `build` to `BUILD_MENU` types), `issueWallUpgrade` (sim/production.js, queue item `upgrade: true`), `world.changeBuildingType`, `findBreach` and the `findTarget` skip (sim/combat.js), breach orders (sim/orders.js), `defeatPlayer` (sim/world.js, kills a defeated player's walls), `s.cut` in sim/surround.js.
- Wire: the sanitizer whitelists `tx2/ty2` and `upgradeWall { walls }` (id lists are capped at 256). A segment is an ordinary building view, so the stone swap rides the delta stream; tests/net/walls-wire.test.js follows one into the ViewState (the first building whose type changes).
- Render: a connection mask per segment (bits N E S W; the same bits shifted by 4 mark a tower neighbour), geometry cached per (style, mask), `GameRenderer.syncWallJoins` once per snapshot, two meshes a segment so long walls stay cheap, `showWallLine` ghost line, slim overlays, no yard painting. Model budgets: [gods-titans-graphics](gods-titans-graphics.md). Since the buildings pass (#26) the segments are rounded: wooden stakes are six-sided logs at lod 1 and five-sided when all four arms are tower arms (mask 255 must stay at level 1 inside the 700 budget; a test checks every mask), stone piers and arms use the local `bev`/`armBev` in `buildStoneWall`. See [buildings-kit-code-map](buildings-kit-code-map.md), [buildings-budgets-and-shots](buildings-budgets-and-shots.md).
- Ghost: `checkWallLine(vs, me, type, x0, y0, x1, y1, planned, workers)` in game/placement.js mirrors `issueBuildLine` tile for tile (texts repeated there); input.js `workerSpots()` feeds it the selected workers.
- HUD: wall card in ui/command-card.js (U upgrade, D dismantle), wall-only selections up to 160 (ui/hud-selection.js), crowd panel (ui/hud-info.js; its rebuild signature holds `typeMix`, so stone swaps show), minimap squares, one "breached" message per 6 s (game/game.js).
- Gotchas: loops over `buildingList` for "real" buildings must skip `def.wall`. Icons in src/data and src/ui must be Emoji up to version 11 (a test enforces it). Quote `node --test` globs. Sim tests use `ringWorld(type, opts)` from tests/sim/walls.test.js; render tests register an import map for 'three'.
